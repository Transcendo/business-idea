# 医疗后台 AI 执行层

## 一句话判断

今天更值得持续跟的，不是单一“医疗 AI 工具”，而是**医疗后台 agent 正在变成可验证的执行层**：围绕 intake、chart prep、referral、scheduling、patient communications、inbox triage 这些高频 SOP，去接管诊所和 health system 的后台工作。

## 为什么这条线值得看

- **买单方清楚**：诊所、医疗集团、运营团队。
- **痛点清楚**：后台行政和协调工作吃掉大量人力。
- **ROI 可讲**：节省 coordinator / MA 时间，减少延误和漏单。
- **产品边界更实**：先做具体流程，而不是泛泛对话助手。

## 核心判断

医疗 AI 的创业价值，越来越不在“能不能生成”，而在：

1. 能不能嵌进现有 EHR / RCM / 运营流程
2. 能不能对例外情况做验证与回退
3. 能不能把 SOP 变成可审计的执行系统

这类产品如果跑通，护城河会来自**流程嵌入、合规、信任、部署深度**，而不是模型本身。
