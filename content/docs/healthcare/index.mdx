# 医疗健康

这里放 provider 工作流、患者服务、临床 AI、生物软件 等方向。

## 重点子方向
- 临床效率工具
- 医疗文档与辅助决策
- 患者服务与运营
- 医药研发效率工具
- 合规与数据基础设施

## 当前已收录
- [Preact Health](/docs/healthcare/preact-health) → 个人 health score + health system care gap detection 的双产品线
- [医疗后台 AI 执行层](/docs/healthcare/healthcare-backoffice-execution-layer) → 诊所和 health system 的后台 agent 执行层
- [DrSwarm](/docs/healthcare/drswarm) → 诊所和小型 health system 的 AI operations team
- [AutoICD MCP](/docs/healthcare/autoicd-mcp) → 临床编码、审计和去标识化的 MCP 工具层
- [Abridge](/docs/healthcare/abridge) → 医疗对话驱动的临床文档、编码与收入循环基础设施
- [Nabla](/docs/healthcare/nabla) → ambient clinical documentation 与 EHR 内临床文档入口
- [OpenEvidence](/docs/healthcare/openevidence) → 医学证据入口向 EHR 决策、编码与 prior auth 工作流扩张
- [No Barrier](/docs/healthcare/no-barrier) → 医疗口译与语言访问的实时 AI 基础设施
- [BitBoard](/docs/healthcare/bitboard) → 医疗后台行政与 SOP 化 agent 执行层
- [Infinitus](/docs/healthcare/infinitus) → payer member services 的 healthcare agent layer
- [Qualified Health](/docs/healthcare/qualified-health) → health system 的 AI 治理、部署与控制层
- [Mandolin](/docs/healthcare/mandolin) → specialty drug access 的 AI 后台操作系统
- [Luminai](/docs/healthcare/luminai) → 医院行政与运营工作流自动化
- [百川智能](/docs/healthcare/baichuan) → 医疗健康 / 中国基础模型
- [Suki Nursing Assistant](/docs/healthcare/suki-nursing-assistant) → 护理工作流、表单与 EHR 内 AI 助手扩展
