# 本周新增

本页只放当前周新增或重点更新的公开页面；旧的长期参考案例已经移到 [精选案例](/docs/weekly-picks)。

当前统计周期：**2026-05-11 至 2026-05-17**。5 月 11 日主要是开放世界游戏专项 inbox 笔记，没有新增公开正式页。

## 2026-05-16

- [Agent Tool Distribution Layer](/docs/developer-tools/agent-tool-distribution-layer)：AI agent 接工具之后，团队缺的不是更多 MCP demo，而是可安装、可复用、可审计、可回滚的技能与工具分发层。
- [Mobile GUI Agent Runtime](/docs/ai-agents/mobile-gui-agent-runtime)：手机 agent 的机会不是再做一个聊天 App，而是把真实 Android / iOS 屏幕、权限、点击、输入、回放和人工接管变成可验证的任务运行时。
- [Local LLM Hardware Fit Layer](/docs/ai-hardware/local-llm-hardware-fit-layer)：本地 LLM 的痛点不是再多一个模型榜单，而是判断某台真实机器上哪个模型跑得动、跑得快、质量够用，并把这个判断变成可复测的配置。

## 2026-05-15

- [Realtime Voice Agent Runtime](/docs/ai-agents/realtime-voice-agent-runtime)：实时语音 agent 的缺口不只是模型接电话，而是低延迟、打断、转人工、业务写入和质检回放组成的任务运行时。
- [Agent Identity Policy Runtime](/docs/cybersecurity/agent-identity-policy-runtime)：多 agent 委派、工具调用和 SaaS 执行之后，身份、策略和审计 receipt 会变成 agent 安全的底层运行时。
- [Agent Failure Regression Harness](/docs/developer-tools/agent-failure-regression-harness)：把 coding agent 的失败 trace 变成可回放、可断言、可进 CI 的回归测试。
- [Agent Database Branching Sandbox](/docs/developer-tools/agent-database-branching-sandbox)：每个 coding-agent 任务一个可写、隔离、可清理的数据库分支，用真实数据形态验证 migration、backfill 和 schema 变更。
- [Text-to-CAD Hardware Design Agents](/docs/robotics/text-to-cad-hardware-design-agents)：AI coding agent 开始进入 CAD、机器人描述文件和硬件原型链路，把自然语言需求压成可审查、可复现、可导出的工程文件。

## 2026-05-14

- [Agent Traffic Analytics Layer](/docs/ai-agents/agent-traffic-analytics-layer)：判断网站和产品是否能被 AI agent 正确读取、理解和执行。
- [Tiny Tool-Calling Router](/docs/developer-tools/tiny-tool-calling-router)：用小模型做低延迟 `{tool, args, confidence}` 路由，服务本地软件、CLI、桌面和边缘 agent。
- [Agent Structural Memory Layer](/docs/developer-tools/agent-structural-memory-layer)：把长任务 agent 的上下文、代码关系和历史决策组织成可审计的结构化记忆。
- [Agent Context Sandbox Layer](/docs/developer-tools/agent-context-sandbox-layer)：隔离 MCP、shell、浏览器等工具输出，避免上下文窗口被噪声烧穿。
- [Browser Agent Execution Harness](/docs/ai-agents/browser-agent-execution-harness)：本周重点更新，补入 agent-first browser runtime、人类接管和可回放执行线索。

## 2026-05-13

- [Statewright Agent State-Machine Guardrails](/docs/ai-agents/statewright-agent-state-machine-guardrails)：用状态机约束 agent 执行，减少长流程失控。
- [InsForge Agentic Backend](/docs/developer-tools/insforge-agentic-backend)：AI app 生成之后，数据库、鉴权、存储和 AI gateway 成为下一层瓶颈。
- [Hypercubic Hopper Mainframe Agents](/docs/vertical-ai/hypercubic-hopper-mainframe-agents)：面向 mainframe / COBOL 运维的垂直 agent 机会。
- [Code Agent Git Boundary Guardrails](/docs/cybersecurity/code-agent-git-boundary-guardrails)：为 AI coding agent 的 commit、push、CI 和高危 diff 加边界。
- [MiniCPM-V Edge Multimodal Agents](/docs/ai-hardware/minicpm-v-edge-multimodal-agents)：边缘多模态模型让本地视觉 agent 的成本和延迟更接近可用。

## 2026-05-12

- [MCP Agent Security Gateway](/docs/cybersecurity/mcp-agent-security-gateway)：MCP / agent 工具调用安全层，处理 tool poisoning、secret 泄露和运行时拦截。
- [Suki Nursing Assistant](/docs/healthcare/suki-nursing-assistant)：ambient clinical AI 从医生文书下沉到护士 forms、flowsheets 和 handoff。
- [AI Coding Agent Control Plane](/docs/developer-tools/ai-coding-agent-control-plane)：预算刹车、scope guard、verifier gate、rollback evidence 和 run receipt。
- [Browser Agent Execution Harness](/docs/ai-agents/browser-agent-execution-harness)：浏览器 agent 从 demo 走向 replay、失败恢复、live-web eval 和 run card。
- [Agent Session Supervision Layer](/docs/developer-tools/agent-session-supervision-layer)：多 agent / 多 coding session 并行后的 session registry、blocker alert 和 handoff card。
