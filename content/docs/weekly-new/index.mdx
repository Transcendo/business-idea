# 本周新增

本页只放当前周新增或重点更新的公开页面；旧的长期参考案例已经移到 [精选案例](/docs/weekly-picks)。

当前统计周期：**2026-05-18 至 2026-05-24**。

## 2026-05-19

- [Geospatial Foundation Model Evaluation Layer](/docs/vertical-ai/geospatial-foundation-model-evaluation-layer)：地理空间 foundation model 变多后，机会不是再训一个遥感大模型，而是把 AOI、任务、样本、候选模型、误差地图和交付证据压成 model-fit report。
- [Durable Agent Workflow Runtime](/docs/developer-tools/durable-agent-workflow-runtime)：多步骤 AI agent 开始进生产后，机会不是再做一个更花的流程画布，而是把 agent 任务封成可暂停、可恢复、可观测、可审计的 durable workflow runtime。
- [AI QA Release Gate](/docs/developer-tools/ai-qa-release-gate)：AI 生成应用和 coding agent PR 变多后，机会不是再写一个测试框架，而是把上线前冒烟测试、视觉检查、失败证据和人工确认压成 release receipt。
- [Agent Plan Review Layer](/docs/developer-tools/agent-plan-review-layer)：coding agent 进入 Plan Mode 后，机会不是再做一个更会写代码的 agent，而是把执行前计划变成可批注、可退回、可批准的 plan review receipt。
- [AI Video Demo Agent](/docs/ai-agents/ai-video-demo-agent)：B2B SaaS 的机会不是再加一个预约按钮，而是把产品演示、问答、资格判断和 CRM 交接压成即时 demo receipt。

## 2026-05-18

- [Research Agent Citation Verifier](/docs/ai-agents/research-agent-citation-verifier)：Deep Research 变成主流 agent 应用后，机会不是再写一份更长报告，而是把引用、证据、来源覆盖和结论边界压成可复查的 evidence pack。
- [Voice Agent QA Scorecard](/docs/ai-agents/voice-agent-qa-scorecard)：语音 agent 进入生产后，机会从“能接电话”转向“能证明每个版本可以安全放量”的 QA scorecard。
- [Agent PR Review Evidence Layer](/docs/developer-tools/agent-pr-review-evidence-layer)：AI coding agent 开始批量开 PR 后，工程团队缺的不是更多自动改代码按钮，而是把 agent 改动压成可审查、可追责、可合并的 PR evidence packet。
- [Agent Execution Provenance Container](/docs/developer-tools/agent-execution-provenance-container)：agent 开始替团队执行代码、浏览器和后台任务后，下一层机会是把每次运行封成可验签、可转交、可审计的 provenance container。
- [Spreadsheet-Native AI Data Analyst](/docs/developer-tools/spreadsheet-native-ai-data-analyst)：AI 数据分析的新机会不是再做一个聊天式 BI，而是把 spreadsheet 变成可执行、可解释、可分享的 analyst workspace。

## 2026-05-17

- [Headless Coding Agent Runtime](/docs/developer-tools/headless-coding-agent-runtime)：AI coding 的下一层机会不是再做一个 IDE 插件，而是把同一个 coding agent 封成 CLI、SDK、CI/CD、任务队列和产品内嵌自动化都能调用的 headless runtime。
- [AI Debug Evidence Recorder](/docs/developer-tools/ai-debug-evidence-recorder)：AI 编程工具真正缺的不是又一个自动修 bug 按钮，而是把屏幕、控制台、网络、错误、复现步骤和人工标注压成 agent 可读、工程师可审查的调试证据包。
- [Agent-Native API Payment Layer](/docs/fintech/agent-native-api-payment-layer)：AI agent 会把“访问一个网页”升级成“调用一组付费工具完成任务”，新机会是按次支付、预算策略、身份、收据和争议处理层。
- [Computer-Use Agent Sandbox Runtime](/docs/ai-agents/computer-use-agent-sandbox-runtime)：Computer-use agent 的机会不是再做一个会点屏幕的助手，而是把完整桌面、浏览器、终端、文件、登录态、轨迹监控和人工接管封成安全可复跑的任务运行时。
- [Agentic Commerce Product Discovery Layer](/docs/consumer-ai/agentic-commerce-product-discovery)：AI 购物 agent 的机会不是再做一个导购聊天框，而是把商品发现、库存价格、商家可信度和可控下单变成 agent 可调用的商品判断层。

## 2026-05-16

- [Agentic Security Evaluation Harness](/docs/cybersecurity/agentic-security-evaluation-harness)：Agent 安全的新机会不是再喊一遍“要加权限控制”，而是把 agent、工具、身份、策略、攻击面和修复规则放进可重复运行的安全评测 harness。
- [AI SOC Triage Runtime](/docs/cybersecurity/ai-soc-triage-runtime)：安全团队缺的不是又一个会总结告警的聊天框，而是把告警、工具调用、证据、判断和复盘串成可回放的 triage run。
- [Agent Tool Distribution Layer](/docs/developer-tools/agent-tool-distribution-layer)：AI agent 接工具之后，团队缺的不是更多 MCP demo，而是可安装、可复用、可审计、可回滚的技能与工具分发层。
- [Mobile GUI Agent Runtime](/docs/ai-agents/mobile-gui-agent-runtime)：手机 agent 的机会不是再做一个聊天 App，而是把真实 Android / iOS 屏幕、权限、点击、输入、回放和人工接管变成可验证的任务运行时。
- [Local LLM Hardware Fit Layer](/docs/ai-hardware/local-llm-hardware-fit-layer)：本地 LLM 的痛点不是再多一个模型榜单，而是判断某台真实机器上哪个模型跑得动、跑得快、质量够用，并把这个判断变成可复测的配置。

## 2026-05-15

- [Realtime Voice Agent Runtime](/docs/ai-agents/realtime-voice-agent-runtime)：实时语音 agent 的缺口不只是模型接电话，而是低延迟、打断、转人工、业务写入和质检回放组成的任务运行时。
- [Agent Identity Policy Runtime](/docs/cybersecurity/agent-identity-policy-runtime)：多 agent 委派、工具调用和 SaaS 执行之后，身份、策略和审计 receipt 会变成 agent 安全的底层运行时。
- [Agent Failure Regression Harness](/docs/developer-tools/agent-failure-regression-harness)：把 coding agent 的失败 trace 变成可回放、可断言、可进 CI 的回归测试。
- [Agent Database Branching Sandbox](/docs/developer-tools/agent-database-branching-sandbox)：每个 coding-agent 任务一个可写、隔离、可清理的数据库分支，用真实数据形态验证 migration、backfill 和 schema 变更。
- [Text-to-CAD Hardware Design Agents](/docs/robotics/text-to-cad-hardware-design-agents)：AI coding agent 开始进入 CAD、机器人描述文件和硬件原型链路，把自然语言需求压成可审查、可复现、可导出的工程文件。

## 2026-05-14

- [Agent Traffic Analytics Layer](/docs/ai-agents/agent-traffic-analytics-layer)：判断网站和产品是否能被 AI agent 正确读取、理解和执行。
- [Tiny Tool-Calling Router](/docs/developer-tools/tiny-tool-calling-router)：用小模型做低延迟 `{tool, args, confidence}` 路由，服务本地软件、CLI、桌面和边缘 agent。
- [Agent Structural Memory Layer](/docs/developer-tools/agent-structural-memory-layer)：把长任务 agent 的上下文、代码关系和历史决策组织成可审计的结构化记忆。
- [Agent Context Sandbox Layer](/docs/developer-tools/agent-context-sandbox-layer)：隔离 MCP、shell、浏览器等工具输出，避免上下文窗口被噪声烧穿。
- [Browser Agent Execution Harness](/docs/ai-agents/browser-agent-execution-harness)：本周重点更新，补入 agent-first browser runtime、人类接管和可回放执行线索。

- [Hypercubic Hopper Mainframe Agents](/docs/vertical-ai/hypercubic-hopper-mainframe-agents)：面向 mainframe / COBOL 运维的垂直 agent 机会。
- [Code Agent Git Boundary Guardrails](/docs/cybersecurity/code-agent-git-boundary-guardrails)：为 AI coding agent 的 commit、push、CI 和高危 diff 加边界。
- [MiniCPM-V Edge Multimodal Agents](/docs/ai-hardware/minicpm-v-edge-multimodal-agents)：边缘多模态模型让本地视觉 agent 的成本和延迟更接近可用。
