# 本周新增

本页只放当前周新增或重点更新的公开页面；旧的长期参考案例已经移到 [精选案例](/docs/weekly-picks)。

当前统计周期：**2026-05-18 至 2026-05-24**。

## 2026-05-24

- [Computer-Use Trajectory Data Foundry](/docs/ai-agents/computer-use-trajectory-data-foundry)：Computer-use agent 真正缺的不是又一个会点屏幕的 demo，而是高质量任务轨迹、失败轨迹、人工修正和可授权复用的数据资产。
- [Agent Database Access Firewall](/docs/cybersecurity/agent-database-access-firewall)：AI agent 开始直连数据库后，机会不是把生产库凭证塞给聊天工具，而是在查询执行前加一层只读、脱敏、限表、限额和审计防火墙。
- [Agent Dev-Machine Exposure Scanner](/docs/cybersecurity/agent-dev-machine-exposure-scanner)：AI agent 进入本地开发机后，机会不是再劝开发者“注意安全”，而是把 MCP server、IDE 插件、agent CLI、环境变量、包安装和工具权限压成可复查的暴露面报告。

## 2026-05-23

- [Agentic HTML Deliverable Compiler](/docs/ai-agents/agentic-html-deliverable-compiler)：AI 内容工具的新缺口不是再写一段文本，而是把草稿、来源、品牌规则、预览、导出和客户说明压成可复跑的 HTML 交付物与 delivery receipt。
- [Agentic Video Editing Command Layer](/docs/ai-agents/agentic-video-editing-command-layer)：创作者和增长团队的视频机会不是从 0 生成炫片，而是把素材理解、剪辑动作、多版本导出、品牌约束和风险提示压成可复跑的 editing receipt。
- [Agent Execution-Layer Security Sandbox](/docs/cybersecurity/agent-execution-layer-security-sandbox)：AI coding agent 开始在真实仓库里跑 shell、读文件、发网络请求和接触密钥后，机会不是再写一层 prompt 安全，而是在执行层给每个 agent run 加文件、网络、进程、密钥和审计边界。
- [Messaging-Native Coding Agent Command Center](/docs/developer-tools/messaging-native-coding-agent-command-center)：Coding agent 进入长任务和多 session 后，缺口不是再做一个 IDE 插件，而是把开始任务、实时输出、风险批准、暂停恢复和交接压进 Slack、Discord、Telegram、微信、飞书这类消息入口。
- [Agent-Readable Database Contract Layer](/docs/developer-tools/agent-readable-database-contract-layer)：Coding agent 开始改 schema、migration 和数据访问层后，缺口不是再包一层 ORM，而是把数据库结构、迁移计划、查询边界和 drift 证明变成 agent 可读、可验证的 contract。

## 2026-05-22

- [Agent Side-Effect Replay Ledger](/docs/developer-tools/agent-side-effect-replay-ledger)：Agent 开始接邮箱、CRM、数据库、工单和浏览器后，危险点不只是回答错了，而是失败重试把同一个外部动作执行两遍；机会是把 intent、effect receipt、幂等键、人工批准和 replay decision 压成可审查的副作用账本。
- [AI App Unit Economics Ledger](/docs/developer-tools/ai-app-unit-economics-ledger)：AI app 的成本问题不只在模型账单，而是用户、功能、工作流和 agent 动作到底有没有赚钱；机会是把产品事件、LLM trace、工具调用和收入事件压成 task-level 毛利账本与预算刹车。
- [Agent Virtual Filesystem Layer](/docs/developer-tools/agent-virtual-filesystem-layer)：Agent 工具越来越多，真正卡住的不是再接一个 API，而是让模型用统一路径、权限和读写语义处理 Slack、GitHub、S3、数据库、RAG 和本地文件。
- [Agent Codebase Retrieval Compression Layer](/docs/developer-tools/agent-codebase-retrieval-compression-layer)：Coding agent 进入真实仓库后，最贵的不是生成代码，而是反复 grep、read、猜文件、塞上下文；机会是把代码检索压成 agent 可复查的最小证据包。
- [Repo Preference Pack for Coding Agents](/docs/developer-tools/repo-preference-pack-for-coding-agents)：Coding agent 会写代码之后，下一层摩擦是它不懂每个仓库的口味、禁区和历史坑；机会是把 merge history、review comment 和 revert 压成 agent 可执行的团队偏好包。

## 2026-05-21

- [MCP Cross-Client Testing Layer](/docs/developer-tools/mcp-cross-client-testing-layer)：MCP app 的新痛点不是本地 server 能不能跑，而是同一个工具在 ChatGPT、Claude、Cursor、IDE 等客户端里能不能稳定调用、可回放、可进发布 gate。
- [Agent Tool-Calling Guardrails Layer](/docs/developer-tools/agent-tool-calling-guardrails-layer)：Agent 开始调用 shell、浏览器、MCP 和内部 API 后，机会不是再换一个更强模型，而是把破损 tool call、漏步骤、上下文超限和失败回放压成可靠性 proxy 与 run receipt。
- [Agent-Readable Docs Readiness Layer](/docs/developer-tools/agent-readable-docs-readiness-layer)：Coding agent 开始替开发者读 docs、接 API、调 MCP 后，机会不是更漂亮的文档站，而是把 docs、repo、API、SDK 和 MCP tool 压成可复跑的 agent-readiness report 与修复 PR。
- [Design System Extraction Layer for Coding Agents](/docs/developer-tools/design-system-extraction-layer-for-coding-agents)：AI coding agent 做前端的缺口不是再多一个生成器，而是把真实网站、品牌规则、设计 token、交互状态和可访问性压成 agent 可执行的设计约束包。
- [AI Coding Package Hallucination Firewall](/docs/cybersecurity/ai-coding-package-hallucination-firewall)：Coding agent 自动写依赖、跑安装、开 PR 后，包名幻觉会从聊天窗口进入供应链；机会是在 agent-generated dependency diff 前做 package risk receipt。

- [AI Search Visibility Action Layer](/docs/vertical-ai/ai-search-visibility-action-layer)：AI 搜索可见性的机会不是再做一个“品牌是否被 ChatGPT 提到”的报表，而是把 AI answer、crawler 可达性、引用来源和内容缺口压成可执行、可复测的修复工单。
- [Demonstration-to-Agent Workflow Trainer](/docs/ai-agents/demonstration-to-agent-workflow-trainer)：Agent 自动化的新切口不是让用户写更长 prompt，而是让用户录一遍真实任务，系统把点击、输入、判断点和异常处理压成可复用、可审查的 workflow agent。
- [AI Coding Token Cost Profiler](/docs/developer-tools/ai-coding-token-cost-profiler)：AI coding agent 的新痛点不是会不会写代码，而是一次任务到底把 token 烧在了哪里；机会是把上下文浪费、成本漂移和无效重试压成 cost receipt。
- [Mobile AI Test Agent](/docs/developer-tools/mobile-ai-test-agent)：移动 App QA 的机会不是再写更多 Appium 脚本，而是把自然语言用例、屏幕观察、动作执行、失败修复和证据报告压成可复跑的测试 agent。
