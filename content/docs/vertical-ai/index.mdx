# 垂直 AI

这里放行业属性强于技术属性的创业方向，而不是通用型 AI 工具。

## 重点子方向
- 食品合规 / HACCP / 审计准备
- Mainframe / legacy enterprise operations
- 法律
- 教育
- 建筑
- 房地产
- AI 搜索 / 增长营销
- 供应链
- 知识工作
- 农业

## 当前已收录
- [Live Prospect Research Agent](/docs/vertical-ai/live-prospect-research-agent) → 销售和 GTM 团队最痛的不是不会写外联文案，而是人人都在买同一批过期数据库；更硬的机会是把 event page、PDF、directory、registry、maps 这类活数据压成可验证的 prospect research workflow
- [AI HACCP Draft-and-Evidence Copilot](/docs/vertical-ai/ai-haccp-draft-and-evidence-copilot) → 食品合规里最痛的不是标准解释，而是把配方、流程、供应商资料和操作记录翻译成 draft HACCP pack、缺失证据清单和持续更新差异
- [AI Search Visibility Action Layer](/docs/vertical-ai/ai-search-visibility-action-layer) → AI 搜索可见性 / GEO / AEO / 营销修复工单
- [Geospatial Foundation Model Evaluation Layer](/docs/vertical-ai/geospatial-foundation-model-evaluation-layer) → 遥感 / 地理空间 foundation model 评估、模型适配和误差报告
- [Hypercubic Hopper Mainframe Agents](/docs/vertical-ai/hypercubic-hopper-mainframe-agents) → Mainframe operations / COBOL / JCL / TN3270 agent workflow
- [Hebbia](/docs/vertical-ai/hebbia) → 知识工作 / 金融 / 法律工作流
