# 消费级 AI

面向个人用户、创作者、消费者和普通信息工作者的 AI 产品机会。

## 新增机会

- [Local-First Video Brief Workspace](/docs/consumer-ai/local-first-video-brief-workspace)：视频摘要工具已经很多，新的机会不是再吐一段 summary，而是把下载、转写、时间戳证据、反驳点和可复查引用压成一个本地优先的研究 brief 工作流。

## 已收录

- [Agentic Commerce Product Discovery Layer](/docs/consumer-ai/agentic-commerce-product-discovery)：AI 购物 agent 的机会不是再做一个导购聊天框，而是把商品发现、库存价格、商家可信度和可控下单变成 agent 可调用的商品判断层。
- [Perplexity](/docs/consumer-ai/perplexity)：AI-native answer engine，把搜索、引用、对话和订阅组合成新的信息入口。
