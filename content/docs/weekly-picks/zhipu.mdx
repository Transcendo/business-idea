# 智谱

如果要在中国 AI 创业公司里挑一个“既想做模型，又想做 Agent，又想做平台和生态”的代表，智谱通常会排在最前面。

它值得关注，不只是因为名气大，而是因为它在国内创业公司里少见地同时踩了几条线，基座模型、Agent 产品、开发平台、政企落地。这种打法的上限很高，但也天然更重、更难、更考验组织能力。

## 这家公司在做什么

从官网和公开信息看，智谱现在已经不是单纯做一个聊天产品，而是在推一整套 GLM 模型和 Agent 体系。

它的公开定位大致包括：

- GLM 系列基础模型
- Agent 相关产品和能力
- 面向开发者与企业的 MaaS / 平台能力
- 与政企、城市和生态伙伴一起做落地

这说明它想做的不是单点应用，而是一个更全栈的中国 AI 平台型公司。

## 为什么值得关注

### 1. 它是国内最像“全栈平台公司”的创业选手之一

很多创业公司会在某一层特别强，比如只做 C 端产品、只做模型、只做某个垂直行业。智谱更像是想把模型、平台、Agent、生态一起推进。

这种路线非常难，但一旦做成，位置会比单点应用更稳。

### 2. 它在 Agent 和开发生态上的布局比较早

官网公开信息里，智谱明显在强化 Agent 能力、工具调用、自主执行和开发套件。这点很关键，因为现在国内真正能把“模型能力”往“可执行系统”推进的公司并不多。

### 3. 它的政企和产业落地能力是一个现实优势

在中国市场，光有模型不够，能不能接住政企和行业场景，决定了很多公司能不能拿到更稳的收入和更长的生存周期。

智谱在这条线上看起来是有组织优势的。

## 投资人视角批判

### 1. 战线太长，组织压力会非常大

模型、Agent、平台、生态、政企，这几条线任何一条都不轻。全都想做，意味着资源分配和组织复杂度会迅速上升。

### 2. 它会长期处在“大厂和创业公司夹击”中

往上看有国内大厂，往下看有更专注、速度更快的创业公司。智谱想守住的平台位置，不会轻松。

### 3. 平台故事很强，但商业质量要持续验证

平台叙事越大，市场越会继续追问真正的收入质量、客户留存和开发者生态粘性，而不是只看技术发布频率。

## 我们的判断

智谱是必须长期跟的中国 AI 公司之一，因为它代表的是一种更重但也更有上限的打法。

但我不会把它简单看成已经坐稳的位置。接下来最关键的，是它能不能把今天的模型与 Agent 叙事，继续沉淀成真正稳定的生态、客户和平台能力。
