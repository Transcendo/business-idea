# AI 智能体

这里放执行型 AI 软件，而不是泛聊天工具。

## 重点子方向
- 销售
- 客服
- 运营
- 金融
- 研究
- Deep Research / citation verification / evidence pack
- 浏览器执行 / 网页自动化
- Computer-use agent / 整机自动化 sandbox
- 移动 GUI agent / 手机 App 自动化
- 实时语音 agent runtime
- Demonstration-to-agent / 示范式 workflow agent 训练
- AI video demo agent / 即时产品演示 / 销售资格判断
- Agentic video editing / 多版本剪辑 / 品牌约束 / editing receipt
- 语音 agent QA / 回归测试 / 放量 scorecard
- Agent traffic / agent-readiness analytics
- 企业治理
